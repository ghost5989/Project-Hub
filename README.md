# Project Hub

A production-ready cyberpunk project showcase with a creator console.

## Features

- Public project showcase with search & category filtering
- Owner-only admin dashboard (CRUD for projects, categories, settings)
- Secure HTTP-only cookie authentication (bcrypt-hashed passwords)
- Per-project GitHub access password protection (server-verified)
- Contact form persisted to JSON storage
- Theme toggle, SEO metadata, responsive design
